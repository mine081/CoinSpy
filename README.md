# Coin Spy

A lightweight, responsive cryptocurrency market scanner that analyzes Binance spot trading pairs quoted in USDT and displays potential buy, sell, or neutral signals.

Coin Spy uses public Binance market data and technical indicators to help users explore market conditions across multiple cryptocurrencies.

## Features

- **Binance market data:** Retrieves 24-hour ticker data and candlestick (kline) data from Binance public API endpoints.
- **Technical indicators:**
  - RSI (14)
  - MACD, using 12- and 26-period EMAs with a 9-period signal line
  - EMA 20 and EMA 50 for trend analysis
- **Signal scoring:** Combines indicator conditions into a score ranging from -5 to +5.
- **Signal categories:** Strong Buy, Buy, Neutral, Sell, and Strong Sell.
- **Timeframes:** 15 minutes, 1 hour, 4 hours, and 1 day.
- **Volume filtering:** Filter trading pairs by minimum 24-hour quote volume.
- **Search and sorting:** Find a cryptocurrency and sort table columns.
- **Expandable details:** View the conditions that contributed to each signal.
- **Automatic refresh:** Optionally refresh market data every 60 seconds.
- **Responsive interface:** Supports light and dark system themes.

## Getting Started

No build tools or package installation are required. Coin Spy is a standalone HTML application.

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Open the project folder.
3. Open `index.html` in a modern web browser.

An internet connection is required to retrieve market data from Binance.

## How It Works

The application retrieves Binance 24-hour ticker information, filters eligible USDT trading pairs, and requests up to 120 candlesticks for each pair using the selected timeframe.

It then calculates technical indicators and assigns points according to these conditions:

| Indicator condition | Score |
| --- | ---: |
| RSI below 30 | +2 |
| RSI below 40 | +1 |
| RSI above 70 | -2 |
| RSI above 60 | -1 |
| MACD crosses above its signal line | +2 |
| MACD crosses below its signal line | -2 |
| MACD is positive without a new bullish crossover | +1 |
| MACD is negative without a new bearish crossover | -1 |
| EMA 20 is above EMA 50 and price is above EMA 50 | +1 |
| EMA 20 is below EMA 50 and price is below EMA 50 | -1 |

The resulting score is translated into a signal:

| Score | Signal |
| ---: | --- |
| +4 to +5 | Strong Buy |
| +2 to +3 | Buy |
| -1 to +1 | Neutral |
| -3 to -2 | Sell |
| -5 to -4 | Strong Sell |

These labels are generated by a technical scoring model. They are not predictions or guarantees of future price movements.

## API Endpoints

Coin Spy uses the following public Binance endpoints:

- `GET /api/v3/ticker/24hr` — 24-hour ticker statistics.
- `GET /api/v3/klines` — candlestick data for each trading pair.

It tries `data-api.binance.vision` first and falls back to `api.binance.com` when appropriate. No API key is required for these public market-data endpoints.

## Limitations

- Coin Spy analyzes spot trading pairs quoted in USDT; it does not place orders.
- API rate limits may interrupt analysis when many symbols are requested. If this happens, wait briefly before refreshing.
- Availability of Binance endpoints may depend on network or regional restrictions.
- Technical indicators are based on historical market data and can produce false or delayed signals.
